## 3. 保守 oracle 语义（重复一遍以防误读）

anchor（组内首次 observation）永不计入；repeat event 只计与组内先前
observation 行集合并集**精确匹配**的行字符（新增/变化/无法机械确认
相同的行一律不计）；gross（repeat 全部字符）与 conservative（removable）
分账本分列。本账本是 **estimated removable chars，不是 token savings**。
