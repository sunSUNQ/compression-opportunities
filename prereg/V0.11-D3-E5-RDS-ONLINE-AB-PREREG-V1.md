## 4. Pairing 与顺序（冻结）

```text
每 pair：same task / repo snapshot / model（deepseek-v4-flash）/
agent（claude-code）/ runtime config；唯一差 = CODE_GUARD_RDS。
顺序：rep 奇数 B 先 T 后；rep 偶数 T 先 B 后（交替，先于首 session
冻结）。strictly sequential；25 min timeout；fresh workdir per
session（express 5.2.1 pin，prepare_workdir 机械准备）。
retry：INFRA_FAILURE（agent 未启动/harness 错误）单次 retry + 原记录
*.excluded_infra；TASK_FAILURE 不 retry。禁止挑 run。
```

## 5. Primary metric（冻结：从 chars 切换到 token）

```text
per session 记录 summary.json usage：input_tokens / output_tokens /
cache_read / cache_creation / total_flow_tokens（四字段和）
per pair：Δinput / Δoutput / Δtotal / relative_total_saving =
(tokens_B − tokens_T) / tokens_B
资格判断以 total task token 为主；marker removed_chars 只是 mechanism
ledger 字段
```

## 6. RDS mechanism ledger（T 臂逐 session）

```text
eligible_events / compressed_events / matched_chars / new_chars /
anchor登记数 / native_fallback_count（rds_ledger.ndjson 机械提取；
B 臂验证恒 0）
token_realization_ratio(pair) = (tokens_B − tokens_T) /
  (matched_chars_pair ÷ 4)   ← 分母规则冻结（chars/4 proxy）
聚合 median 报告；≥0.5 记强，<0.25 记弱
```

## 7. Recovery / trajectory backlash gates（一级 gate）

```text
两臂对比：same_file_reread rate / same+similar command rerun rate /
  tool_call_count / turn_count / trajectory observable chars（全部
  observation+assistant chars）
T 臂专项：marker 出现后的同 path re-read 检测（rds_ledger 对齐
  hook_invoked 时序）
gate：T 的 reread/rerun/turns 相对 B 不得系统性增加（median 级不得
  高于 B + 1）
```

## 8. Correctness gate（独立于压缩收益）

```text
逐 pair oracle：B pass / T pass / B pass-T fail / B fail-T pass /
B fail-T fail 四象限全报告；B PASS→T FAIL 逐个审计原因（不自动归因
RDS，不忽略）
gate：T pass pairs ≥ B pass pairs 且 attributable failure = 0
```
