# V0.11-D3-E4 — Repeated-Delivery Suppression Prototype（PREREG AMENDMENT，FROZEN）

状态：**PREREG AMENDMENT FROZEN**（2026-09-23，早于正式 15K replay）。
实现最小、纯机械、fail-closed 的 **Repeated Delivery Suppression
（RDS）prototype**，统一覆盖 E3 census 已确认的 E2/E3/E14 重复交付
（不做三个独立 compressor）。零模型调用、零真实 Agent、零 production
deploy 修改（prototype 为独立离线模块）、不扩 E12/E13-semantic、
不做 dataset 特判、不为接近 9.6% census 上限放松 exactness（宁可
只吃 4%–6%，稳定、机械、可逆优先）。

## 1. Contract（冻结）

```text
C1 anchor-first       重复组内第一次 observation = O1 full native
                      payload，完整透传，永不压缩
C2 exact-only         只折叠"与某一条先前 observation 的连续行段完全
                      精确一致"的连续行区间。行来源 = 首次交付索引
                      （line text → (observation #, line idx)，机械
                      唯一）；来源不唯一/不连续/跨多条 observation
                      分散 → 该行不折叠（保留原文）
C3 recovery identity  压缩标记格式（可审计，禁止 "same as before"）：
                      [TASCO-RDS omitted: observation #k lines a..b
                       (N chars); new: M chars]
                      k = session 内 observation 序号（1-based）；由
                      marker + 被引用 observation 可逐字节重构原
                      observation（重构契约见 §4）
C4 fail-closed        以下任一 → 整条 observation native（原文透传）：
                      anchor 不可靠 / identity 不确定 / payload 解析
                      异常 / overlap 判定不确定 / 新旧内容无法可靠
                      拆分 / truncation / 账目不一致（matched+new ≠
                      原始 chars）/ provenance 缺失
C5 账目一致           每条压缩 observation：omitted_chars + new_chars
                      == 原 chars（否则 fail-closed）
C6 负例锁定           command same ≠ output same；file same ≠ content
                      same——E2/E3 标签本身不触发压缩，只有行级精确
                      匹配触发
```

## 2. 两个机械模式（冻结；不做 diff semantic folding /
stacktrace collapse / test-result summarization / command-specific
knowledge / AST awareness）

```text
模式 A  exact repeated payload：后续 observation 与某先前 observation
        全部行按序完全一致 → 单 marker（模式 B 的特例，N=全部，M=0）
模式 B  exact line-level overlap + delta：扫描 observation 行序，识别
        与单一先前 observation 行序列连续递增对齐的连续行区间 →
        "lines a..b omitted"；非匹配行原样保留（new part 永不压）。
        行匹配基于 \r\n→\n 统一后的行文本精确相等（Unicode 原文，
        无额外 normalization）；重构取 anchor 行原文，逐字节还原
```

## 3. 测试矩阵（冻结，self-test 锁定）

exact duplicate；partial line overlap；content changed；reordered
lines；same command but different output；same file path but file
changed；missing anchor；stale anchor；truncated payload；malformed
payload；repeated group across unrelated task boundary；multiple
candidate anchors；Unicode/newline normalization；huge repeated
payload；负例×2（command same ≠ output same；file same ≠ content
same）。全部通过 = contract 锁定。

## 4. 离线验收（15K replay，冻结）

```text
R1 oracle capture   prototype_removed_chars ÷ E3 census
                    conservative_removable_chars（捕获率，预期 <100%：
                    census 含乱序/分散行交集，RDS 只吃连续段）
R2 offline observable-char saving 分布（命名纪律：非 token saving）：
                    all sessions / hit sessions 的 p25·median·p75；
                    ≥5% 与 ≥10% session incidence（all 口径）
R3 correctness closure 每个 compressed event + 被引 observation →
                    exact 原文重构，exact-match 必须 = 100%；任一
                    失败 = prototype FAIL
R4 deterministic    排序稳定无随机源；aggregates SHA256；rerun 可复算
```

## 5. 停点

replay + 报告 + 复算完成即 STOP。不跑真实 Agent、不做恢复行为实验、
不解封 hapi。下一轮唯一裁决：prototype 是否足够干净、可逆、离线收益
足够稳定，从而授权 **D3-E5 real Agent A/B**。
