## 1. 事件与重复组（冻结）

事件单位 = (command, observation) 对（E1/E2 已实现的同构解析）。
重复组：E2 = by csim 组（同 sim command 事件序列）；E3/E14 = by path
组（非 shell 同 path 事件序列）。组内 anchor = 第一次 observation，
不计 removable；组内后续事件 = repeats。E14 命中的 reread 事件并入
所属 path 组计算（removable 组级算一次）；E14 在 union ledger 中作
shape 多标签。

## 2. 保守 removable oracle（冻结；纯机械，行级精确匹配）

```text
E3/E14（同文件重读）  repeat event 的 removable = 其 observation 行集
                      合 ∩ 组内先前所有 observation 行集合并集 的字符
                      和（每行在该 event 内只计一次；与任何先前已见
                      行相同即计——无法机械确认相同的一律不计）
E2（同命令重跑）      同上（组 = csim 组）
gross repeated chars  组内全部 repeat events 的 obs_chars 总和
conservative removable 总 removable（跨 shape 去重后，见 §3）
新增/变化行、无法确认相同的行一律不计（保守）
```

## 3. Deduplicated union ledger（防虚高核心 gate，冻结）

```text
事件级：同一 event 被多 shape 命中 → shape 多标签，removable 字符
        只计一次（removable 在其重复组上下文内计算一次）
交叉统计：E2∩E3 / E2∩E14 / E3∩E14 / E2∩E3∩E14 的 session 集与
        payload 级 overlap（多标签 events 占比）
union ledger：session-level removable/qualifying chars 全部基于去重
        后的事件集
```

## 4. Session-level 账本字段（冻结）
