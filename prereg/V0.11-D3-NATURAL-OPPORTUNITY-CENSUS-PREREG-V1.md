## 2. 事件数据（冻结）

每 session 解析 tasco_compression.ndjson（逐 tool result 一行：
tool/scenario/before_chars/access.key/timestamp/strategy/selected/
applied/eligible/eligibility_reason/recovery_detected/test_executed/
test_exit_code）。按 timestamp 排序构成事件序列；position = 序号/总
数；**turns_after_event_proxy = 该事件之后的 tool-result 事件数**
（机械代理，冻结说明：非严格模型 turn 计数）。

## 3. Shape 机械定义（阈值先冻结；按输出形态，非能力名）

```text
S1  large_tool_output        before_chars ≥ 2000（任意 tool）
S2  repeated_command_rerun   shell 同 access.key 出现 ≥2 次
                             （修复→重跑→再验证形态）
S3  multi_rerun_validation   shell 同 access.key ≥3 次（多轮重复验证）
S4  repeated_read            非 shell 工具同 access.key ≥2 次
                             （同文件重复读取）
S5  immediate_reread         非 shell 事件后 ≤2 个事件内同 key 重现
S6  terminal_summary_shape   会话最后 1 个 shell 事件且 before_chars
                             ≥1000
S7  large_failing_output     test_executed=true ∧ test_exit_code≠0
                             ∧ before_chars ≥3000
S7b large_passing_output     test_executed=true ∧ test_exit_code=0
                             ∧ before_chars ≥3000
S8  search_fanout            search/grep 类 tool 且 before_chars
                             ≥2000
tool 分类映射（机械）：tool 值含 "shell"→shell 类；含
"read/file"→read 类；含 "grep/search"→search 类；其他→other
（全量枚举由 analyzer 机械产出，映射规则不依赖枚举结果）
```

## 4. 每 shape 统计字段（冻结）

sessions_with_shape / session_incidence（含该 shape 的 session 数 ÷
256）/ events_with_shape / median_raw_chars / p75_raw_chars /
median_position_in_trajectory / median_turns_after_event（proxy）/
repeat_frequency（该 shape 平均同 key 重复次数）/ downstream_reread_
rate（事件后 5 事件内同 key 重现率）/ downstream_recovery_rate
（事件后 5 事件内 recovery_detected 率）/ existing_compression_
overlap（该 shape 事件 selected|applied=true 比率；b4_vd 标注 VD）/
historical_task_level_delta_if_known（transport←C1 负；terminal←D2
Q1=0；其余 none）/ correctness_risk（涉及 session 的 oracle 通过率）。
