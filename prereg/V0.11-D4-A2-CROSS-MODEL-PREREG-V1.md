## 2. 对照设计（冻结；三组比较）

```text
组 1  Minimax overall（A1 20K）vs Qwen overall（35.3K）——跨 dataset
      + 跨 model + 跨 scaffold 混合（仅参考）
组 2  same-scaffold/different-model（核心对照）：
      OH×Minimax 10K vs OH×Qwen 15K
      SA×Minimax 10K vs SA×Qwen 20.3K
组 3  same-model/different-scaffold：引用 A1（Minimax OH vs SA）+
      Qwen 内部（OH vs SA）
E13 二维  model × scaffold 矩阵（incidence），区分 scaffold effect
      （同 model 差）与 model effect（同 scaffold 差）
```

## 3. 判定规则（冻结）

```text
MODEL_STABLE        同 scaffold 下 Qwen/Minimax incidence 比值 ∈
                    [0.67, 1.5]
MODEL_SENSITIVE     比值 ∈ [0.33, 0.67) ∪ (1.5, 3]
MODEL_SENSITIVE_STRONG 或 INCONCLUSIVE（n<500）按比值与样本量
scaffold 判定沿用 A1（比值 >2× = scaffold-sensitive）
```

## 4. Verdict 规则（冻结）

```text
CROSS_MODEL_VALIDATION_COMPLETE  至少一个 same-scaffold 对照成立且
                                 provenance 绑定（dataset hash +
                                 frame definition + detector commit +
                                 census artifact hash）
CROSS_MODEL_CONFOUNDED           只有跨 scaffold+跨 model 混合对照
NOT_COMPARABLE                   Qwen frame 无法建立对照
```
