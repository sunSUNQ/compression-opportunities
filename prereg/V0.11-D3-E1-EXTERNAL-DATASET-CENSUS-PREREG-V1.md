## 2. 消息结构机械解析（冻结，per harness）

```text
openhands/klear 系  assistant.tool_calls_json = OpenAI function call
                    （function.name + arguments JSON：command/path/
                    view_range 等）；tool role 消息 = observation；
                    exit code = observation 中 "[The command completed
                    with exit code N.]" 模式
swe-agent 系        assistant content 代码块首行为命令；user 消息
                    "OBSERVATION:" 前缀 = observation；exit code 无
                    显式标记 → test 成败用输出特征机械判定
                    （FAILED|ERROR|Traceback → fail；PASSED|passed|
                    all tests passed → pass；无法判定 → 该 shape 排除）
规范化              command：白空格折叠 + 首尾 trim；similar = 去除
                    数字 token 后相等
```

## 3. Shape 机械定义（冻结；与 D3 内部 census 同构 + 数据集特有扩展）

```text
E1  repeated_exact_command      同一规范化 command 出现 ≥2 次
E2  repeated_similar_command    同规范化-去数字 command ≥2 次
E3  same_file_reread            view/read 类命令同 path ≥2 次
E4  overlapping_file_read       同 path 带 view_range/区间参数且区间
                                重叠 ≥2 次
E5  same_search                 grep/find/search 类命令同查询参数 ≥2 次
E6  large_test_success          test 类命令 ∧ observation ≥3000 chars
                                ∧ 显式 exit=0 或 pass 特征
E7  large_test_failure          test 类命令 ∧ ≥3000 chars ∧ exit≠0 或
                                fail 特征
E8  large_lint_output           lint/typecheck 类命令 ∧ ≥3000 chars
E9  large_build_output          build 类命令 ∧ ≥3000 chars
E10 repeated_validation         test/lint 类命令重复 ≥2 次
E11 unchanged_validation        E10 且相邻两次 observation 行集合
                                Jaccard ≥0.8（splitlines 集合交并比）
E12 large_diagnostic            observation ≥3000 chars 且含
                                Traceback|ERROR|Exception 特征
E13 large_output_near_terminal  observation ≥2000 chars 且位于
                                trajectory 后 25% 位置 ∧ 其后
                                observation 数 ≤3
E14 output_followed_by_reread   observation 后 ≤3 次 assistant 轮内同
                                path 重读
E15 output_followed_by_rederivation  observation 后 ≤3 轮内同规范化
                                command 重跑
事件单位 = assistant 命令 + 其 observation 对；chars =
observation content 长度
```

## 4. 每 shape 字段（冻结）

sessions / session_incidence / events / median_chars / p75_chars /
median_tokens_est（chars/4 proxy，冻结说明）/
median_turn_index（归一化位置）/ median_turns_after / repeat_rate /
later_reread_rate / success_session_rate（ground_truth resolved）/
potential_compressible_chars（重复类：与首次出现 observation 的行级
重叠字符数）/ whole_session_context_chars（全部 observation 字符和，
session 级 proxy）。

## 5. Candidate discovery gate（冻结，非 capability PASS 门槛）

```text
session_incidence ≥ 20%  AND  median observation chars ≥ 1000
（与 D3 内部门一致；改门需 amendment 并说明）
三重点方向单独报告：E10/E11（repeated validation）、E3/E4（overlapping
read）、E13（late-trajectory large output——不受现有 terminal_state
classifier 约束）
```

## 6. Verdict 规则（冻结）

```text
PASS — NATURAL_OPPORTUNITY_FOUND  pool 非空 → 按冻结排序键
                                  （session_incidence，并列看 median
                                  chars）列 Top 3，客观指标 + 三重点
                                  状态；不做赢家排名；单候选冻结留待
                                  下阶段（含外部复验计划）
NO_NATURAL_OPPORTUNITY / STOP     pool 空
```
