## 1. 分析口径（冻结）

```text
primary metric      task-level total_flow_tokens
normalized          relative_total_delta = (B − T) / B（per pair）
                    + within-arm relative delta = (rep1 − rep2) / mean
blocking            task identity 为 block（12 task × 2 rep × 2 arm）
outlier policy      不删除任何 pair；全分布报告（分位数 + 原始表）
effect sizes        true effect ∈ {+3%, +5%, +10%}
power target        detection probability ≥ 0.80（方向正确 + 显著）
candidate reps      每 task 每 arm ∈ {2, 3, 5, 8, 10}
seed                42 固定；10,000 Monte Carlo trials；deterministic
方法（双交叉）      ① task-blocked bootstrap（按 task 保留结构重采样
                    replicate 差分）② permutation/randomization
                    （treatment label 置换，非参数）
```

## 2. 三层方差分解（冻结定义）

```text
A between-task    12 task 的 mean total tokens 变异（CV）
B within-task     同 task 同臂 rep1 vs rep2 的 relative delta 分布
                  （12 B-pairs + 12 T-pairs = 24 个无 treatment 差分）
                  ← 核心噪声
C mechanism       D5 T 臂 rds matched_chars/4 的 per-session token
                  proxy ÷ session total tokens → 机制暴露率
signal:noise      C 层典型值 vs B 层 std 的量级比
```

## 3. 同臂基线（单 pair 无功效的正式测量）

```text
同臂 replicate 对：B1 vs B2、T1 vs T2（无任何 treatment 改变）
输出其 |relative delta| 分布，与 D5 B/T pair 的 |relative delta|
同图对齐 → within-arm noise ≈/> treatment delta 的正式化
```

## 4. Power simulation（冻结）

```text
模型    per-pair observed relative delta = true_effect + noise；
        noise ~ task-blocked bootstrap 于 within-arm replicate 差分
        分布（跨 task 重采样，保持 block）
模拟    r ∈ {2,3,5,8,10} × effect ∈ {3,5,10}% × 10,000 trials
输出    detection probability（估计方向正确 ∧ |estimate| ≥ effect/2
        的经验频率）、CI width（bootstrap percentile）、false-sign
        probability、方向正确概率
```

## 5. 设计对比（同预算 120 sessions，冻结）

```text
12 tasks × 5 reps/arm vs 30 tasks × 2 reps/arm vs 24 tasks ×
2.5（近似 24×2=96 对齐比较）——判别：B 层 std vs B/T delta std
的相对大小 → 噪声主导源 → reps 或 tasks 哪个优先
```

## 6. 机制量 sanity check（冻结）

```text
D5 T 臂 matched_chars/4 ÷ session total tokens = 机制暴露率分布
→ mechanism-derived detectable target（非在线真实 saving）
回答：3%/5%/10% 中哪些在当前 RDS 触发量下机制上现实可期待
```

## 7. RECOMMENDED_NEXT_BATCH（机械导出规则）

```text
由 §4 power 曲线 + §6 机制暴露率联合决定：
- 若存在 r* 使 target effect 的 power ≥ 0.80 且机制暴露支持 →
  RECOMMENDED_NEXT_BATCH = {tasks × r*×2 arms, estimator, stopping
  rule, cost multiple}
- 若机制暴露率 < 1%（当前触发量下不可能达到 3% 效应）→
  CURRENT_RDS_EFFECT_TOO_SMALL_FOR_COST-JUSTIFIED_ONLINE_QUALIFICATION
不人工偏好；结论机械导出。
```

batch 最小合理设计。全部模拟固定 seed 可 replay。完成后 STOP；
下一轮裁决 = RDS 是否值得真实 Agent 成本继续 qualification。
