## 1. Attribution rubric（机械判定树，先冻结）

对每个 test-fix 负收益 pair（8 个），先计算机械指标再套判定树。

### 指标（全部机械，从 trace 提取）

```text
D1  first_divergence_pos    B/T 命令 csim 序列第一个不同的事件位置
M1  first_marker_pos        T 第一个 RDS compressed 事件位置
A/B 情况                    A = D1 > M1（marker 前两臂一致）；
                            B = D1 ≤ M1（marker 前已分叉）；差 ±1 内
                            记 borderline-A
I1  reread_anchor_path      marker 后 ≤5 事件内 view/cat 类命令 path ==
                            compressed 事件或其 anchor 事件的 path
I2  rerun_same_cmd          marker 后 ≤5 事件内 csim == compressed/
                            anchor 命令 csim
I3  test_rerun_after        marker 后 ≤5 事件内 test 类命令（任意）
I4  explicit_full_output    marker 后 assistant 文本含
                            (完整输出|full output|cat |view |再次执行|
                            重新运行|run again)
I5  anchor_line_reconsume   后续任一 observation 包含被折叠行原文
                            （折叠行集合 = E4 逻辑重放该 T session）
```

### 判定树（冻结顺序）

```text
1. 情况 B（D1 ≤ M1）            → UNRELATED_TRAJECTORY_DIVERGENCE
2. 情况 A ∧ (I1 ∨ I2 ∨ I5)      → RDS_INFORMATION_RECOVERY
3. 情况 A ∧ (I3 ∨ I4)           → RDS_REASONING_COMPENSATION
4. 情况 A ∧ 无 indicator        → NO_ATTRIBUTABLE_CAUSE（方差）
5. borderline-A 有 indicator    → 归 2/3（标注 borderline）
全部 8 pair 的归因分布决定 aggregate verdict（§6）
```

## 3. Marker-local backlash（冻结窗口 = 后 1/3/5 事件）

对 T 每个marker 窗口统计：same-file reread / same-command rerun /
similar test rerun / additional validation（test/lint 类）/
anchor 再消费（I5 行级）。Native 对照 = B session 中同 task 同 rep
的对应 observation（按 csim 匹配定位）后同窗口。输出 T vs B 的
窗口级指标对比（"marker 后是否局部提高重新获取确定性行为"）。

## 4. 被折叠内容 taxonomy（E4 逻辑重放 T session，行级分类）

```text
passing-test repetition / failing-test detail / assertion expected-
actual / stack trace / file-path-line information / summary-count /
command boilerplate / other
判定（行级模式，冻结）：PASSED|✓|passed → passing；FAILED|✖|assert
Error|expected → failing-detail；Traceback|at .*\( → stack；
\.js:\d+|:\d+: → path-line；passed|failed \d+|total → summary；
^\s*(\$|>|npm|node|npx) → boilerplate
回答：被省掉的是"无用重复"还是"test-fix 阶段仍需反复看到的
task-state evidence"
```
