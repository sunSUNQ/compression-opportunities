## 1. Producer taxonomy（机械分类，优先级先冻结）

命令解析沿用 E1（openhands tool_calls_json / swe-agent 代码块）。分类
按优先级先匹配先得：

```text
test            pytest|npm test|mocha|jest|vitest|go test|cargo test|
                make test|tox|unittest
lint            eslint|ruff|flake8|pylint|pre-commit
typecheck       mypy|tsc|pyright|pyre
build           make|npm run build|gradle|mvn|cmake|cargo build|gcc|g++
git             git diff|status|log|show|branch|commit
package-install pip|pip3|npm install|yarn add|poetry (add|install)|conda
search          grep|rg|ag|ack|find
file-read       view|open|cat|head|tail|less|sed|str_replace_editor view
runtime-execute python|node|perl|ruby 直接执行（非上述模式）
generic-shell   cd|ls|echo|pwd|mkdir|touch|mv|cp|rm|export 等其他 shell
other           无法可靠分类（含 harness 内建非 view 命令）——禁止人工猜
```

每 producer category 输出：event count / session count / session
incidence / median·p75·p90 chars / terminal turn distance（其后
observation 数）。

## 2. Payload structure（行级特征比率；阈值先冻结）

对每个 E13 observation 计算行级比率，primary structure = 过阈值比率
最高者（多标签全报告）：

```text
stacktrace/diagnostic-like   ≥0.10 行匹配 File "…", line N |
                             ^\s+at .+\( | Traceback | Caused by
test-case-list               ≥0.15 行匹配 ^[✓✖×]|PASSED|FAILED|PASS |
                             FAIL |test_.*\.\.\.|passed|failed
diff-like                    ≥0.05 行首 @@|diff --git|+++|--- |Index:
table/list-like              ≥0.30 行为 ≥2 列固定分隔（| 或 ≥2 连续
                             空格列结构）
source-code-like             ≥0.40 行首缩进 ∧ ≥0.15 行含 code tokens
                             （def |class |function |import |from |= |{）
unstructured                 以上全部低于阈值
另计（不参与 primary）：line count / unique-line ratio /
exact-duplicate-line ratio / consecutive-repeated-block chars ratio
（连续相同行 run 除首行外字符占比）/ prefix-suffix-repeat proxy
（前 5 行与后 5 行是否互为重复）
```

## 3. Compressible-region proxy（两个保守 proxy；冻结算法）

```text
dedup_only_removable            保留首次出现的重复行字符和
structure_collapse_removable    dedup_only + 连续重复行 run 除首行外
                                字符和（prefix/suffix 跨事件重复不
                                计入——保守）
removable_ratio = removable / obs_chars
输出：全体 E13 与各 producer category 的 p25/median/p75 ratio
命名纪律：仅为 conservative mechanical proxy，禁止表述为最终
token saving
```
